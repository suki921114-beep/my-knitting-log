## 2단계 · 앱 콘텐츠 설문 (1시간)

```
Play Console → 대시보드 → 아래로 스크롤 → '앱 설정' 카드
```

또는 주소창에 `.../app-content` 를 붙여 바로 이동.

목록에 있는 것을 위에서부터 하나씩. **하나라도 비면 출시가 막힙니다.**

- [ ] **개인정보처리방침** — URL 넣기 (아래 3단계에서 만든 주소)
- [ ] **앱 액세스 권한** → "모든 기능을 제한 없이 사용할 수 있음"
- [ ] **광고** → 아니요
- [ ] **콘텐츠 등급** — 설문 답하면 자동 산정 (전체이용가 나올 것)
- [ ] **타겟층 및 콘텐츠** → 13세 이상, 아동 대상 아님
- [ ] **데이터 보안** ← `data-safety.md` 그대로 옮겨 적기
- [ ] **정부 앱** → 아니요
- [ ] **금융 features** → 아니요
- [ ] **건강 앱** → 아니요

## 3단계 · 개인정보처리방침 주소 확보

앱 안의 `/privacy` 화면이 인터넷에서 열려야 합니다.

- [ ] Vercel 배포 주소 확인 (예: `https://뜨개일기주소.vercel.app`)
- [ ] 브라우저에서 `그주소/privacy` 열어서 실제로 보이는지 확인
- [ ] 그 주소를 2단계의 개인정보처리방침 칸에 넣기

⚠️ 앱 안에서만 보이고 웹에서 안 열리면 심사에서 반려됩니다.

## 4단계 · 그래픽 만들기 (제일 오래 걸림)

```
Play Console → 사용자 늘리기 → 앱 정보 → 스토어 등록정보
```

### 반드시 있어야 하는 것

- [ ] **앱 아이콘** 512 × 512 PNG (이미 있음)
- [ ] **피처 그래픽** 1024 × 500 ← **없으면 출시 자체가 안 됨**
- [ ] **휴대전화 스크린샷 2장 이상** (4~8장 권장)

### 있으면 좋은 것

- [ ] 7인치 태블릿 스크린샷
- [ ] 10인치 태블릿 스크린샷

없어도 출시는 되지만, 태블릿 쓰는 분들에게 덜 노출됩니다.

### 스크린샷에 넣을 화면

1. 홈 — 진행중 프로젝트와 단수 카운터
2. **도안 보며 뜨기** — 화면이 갈라진 모습 ← 가장 보여줄 만한 것
3. 도안 PDF 뷰어
4. 실 라이브러리 — 잔여량 막대가 보이는 목록
5. 프로젝트 상세
6. 다이어리

**피처 그래픽 만들 때** — 문어 캐릭터와 앱 이름을 크게. 스토어 목록에서
작게 줄어드니 글자를 많이 넣으면 안 읽힙니다.

## 5단계 · 스토어 문구 (아래 그대로 쓰셔도 됩니다)

### 앱 이름 (30자)

```
뜨개일기 — 뜨개 기록장
```

### 간단한 설명 (80자)

```
단수 세고 도안 보고 실 관리까지. 뜨개하는 사람을 위한 기록장이에요.
```

### 자세한 설명 (4000자)

```
뜨개하면서 남기는 기록장이에요.
로그인 없이 바로 쓸 수 있습니다.


■ 도안 보면서 단수 세기

화면이 위아래로 갈라집니다.
위에서 단수를 세고, 아래에서 도안을 봐요.
한 단 뜰 때마다 화면을 왔다 갔다 할 필요가 없습니다.

뜨는 동안 화면이 꺼지지 않아요.


■ 도안 PDF

사둔 도안 PDF를 넣어두면 앱에서 바로 볼 수 있어요.
손가락으로 벌리면 보고 싶은 자리가 확대됩니다.
보던 장을 기억하니 앱을 닫았다 열어도 그 자리부터예요.
인터넷 없이도 열립니다.


■ 실 관리

가진 실을 등록해 두면 잔여량이 자동으로 계산돼요.
100g당 길이를 적어두면 남은 길이도 알려줍니다.
콘사 쓰시는 분들 편하실 거예요.

일반실과 염색실을 나눠 볼 수 있고,
다 쓴 실은 숨겨둘 수 있습니다.


■ 게이지로 찾기

"이 실에 맞는 도안이 뭐가 있더라?"

실과 도안 양쪽에 게이지를 적어두면
4.0mm, 22코 처럼 쳐서 서로 맞는 짝을 찾을 수 있어요.


■ 뜨개 다이어리

날짜별로 몇 단 떴는지, 어땠는지 사진과 함께 남겨요.
프로젝트를 골라두면 그동안의 기록이 쭉 이어집니다.


■ 라이브러리

실 · 도안 · 바늘 · 부자재를 한곳에 모아둬요.
바늘은 대바늘/코바늘, 줄바늘/조립식까지 나눠 담습니다.
한 번에 검색해서 찾을 수 있어요.


■ 백업

설정에서 파일 하나로 내보낼 수 있어요.
사진까지 전부 들어갑니다.
기기를 바꾸기 전에 한 번 받아두세요.


만들면서 계속 고치고 있습니다.
불편한 점은 설정 → 의견 보내기로 알려주세요.
```
