## 본문

```
안녕하세요, 뜨개일기를 만든 쿠쿠다스입니다.

9월 1일, 뜨개일기가 Google Play에 정식으로 출시되었습니다.
테스트를 도와주신 여러분 덕분입니다. 정말 고맙습니다.

▶ https://play.google.com/store/apps/details?id=com.suki.knittinglog


■ 여러분이 찾아주신 것들

혼자 만들었다면 그대로 나갔을 문제들이 많았습니다.

· 저장하고 뒤로가기를 눌러도 화면이 그대로이던 것
· 실을 삭제하고 뒤로 가면 "삭제된 실"이 뜨던 것
· 사진이 2MB를 넘으면 백업이 안 되던 것
· 프로젝트 화면에서 다이어리 단수가 안 보이던 것

기능도 여러분 의견에서 나왔습니다.

· 도안을 3개까지 넣기 (차트랑 사이즈 도안이 따로 있다는 말씀에서)
· 도안에 형광펜 긋기
· 게이지로 실과 도안 찾기
· 실·부자재에서도 바로 사진 찍기

"이건 좀 불편해요" 한마디가 전부 코드가 되었습니다.


■ 테스트 버전을 쓰고 계셨다면

정식 출시에 맞춰 테스트 참여를 종료했습니다.
앱을 지우거나 다시 받으실 필요는 없습니다. 기록도 그대로 남습니다.
앞으로는 일반 업데이트처럼 정식 버전을 받으시게 됩니다.

지금 버전은 앱 안에서 확인하실 수 있어요.
설정 → 맨 아래 '뜨개일기 정보' → 1.11.0 이면 최신입니다.

아직 낮은 번호라면 업데이트가 아직 안 온 것입니다.
하루쯤 기다리시거나, Play 스토어에서 직접 확인해 주세요.
Play 스토어 → 오른쪽 위 프로필 → 앱 및 기기 관리 → 업데이트 확인

그리고 이 참에 한 번만 백업해 두시면 마음이 놓입니다.
설정 → 백업 → '내 기기로 내보내기'
파일 하나에 사진까지 전부 담깁니다.


■ 앞으로도

불편한 점은 앱 안에서 바로 보내실 수 있습니다.
설정 → 의견 보내기

지금은 위젯과 아이폰 버전을 고민하고 있습니다.
"이런 게 있으면 좋겠다" 싶은 게 있으면 언제든 말씀해 주세요.

다시 한번 고맙습니다.
좋은 뜨개 하세요 🧶

쿠쿠다스 드림
knits2crochet@gmail.com
```

## 넣을지 고민되는 것

**리뷰 부탁** — 초기 평점에 도움이 되지만, 감사 메일에 부탁이 섞이면
고마움이 옅어집니다. 며칠 뒤 따로 한 번 여쭙는 편이 낫습니다.

굳이 지금 넣는다면 맨 끝에 한 줄로만:

```
· 쓰시다가 마음에 드시면 스토어에 한 줄 남겨주셔도 큰 힘이 됩니다.
```

**Thanks to 는 넣지 않기로 했습니다.** 명단은 한 번 만들면 계속 관리해야 하고,
넣고 빼는 데 매번 앱 업데이트가 필요합니다. 답장 안 주신 분이 자동으로
빠지는 모양새도 어색합니다. 이 메일에서 다 같이 인사드리는 것으로 충분합니다.

`src/pages/About.tsx` 의 `THANKS_TO` 는 비어 있어 화면에 나오지 않습니다.
나중에 마음이 바뀌면 배열에 아이디만 넣으면 됩니다.
