## 이번 빌드에 들어간 것 (1.9.0 ~ 1.10.1)

테스터분들께만 드리는 안내가 필요하면 이 목록을 쓰세요.

- 도안 파일을 한 도안에 3개까지 (차트 / 사이즈 옵션)
- 도안에 형광펜 — 색 4가지, 진하기·굵기 조절
- 형광펜이 아래 글자가 비치게 (기본 진하기 50%)
- 형광펜 색이 늘 보이게 (전에는 버튼을 눌러야 나왔음)
- 큰 사진(2MB 초과) 자동 줄여서 백업
- 프로젝트 메모가 백업에서 빠지던 문제
- 뒤로가기가 한 번에 안 먹던 문제
- 프로젝트 화면 다이어리 줄에 단수 표시
