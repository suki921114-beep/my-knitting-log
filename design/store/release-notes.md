# 뜨개일기 출시 준비물 — 현재 버전

versionName `1.8.1` / versionCode `34`

> 이 파일 하나만 씁니다. 버전이 올라가면 여기 내용을 덮어쓰세요.
> `release-notes-1.7.*.md`, `release-notes-1.8.0.md` 는 지우셔도 됩니다.

## 담은 범위

**이번 버전에서 바뀐 것만** 적습니다.

도안 PDF·뜨기 모드는 versionCode 31 로 이미 나갔습니다. 지난 내용을 다시 넣으면
쓰던 기능이 새로 나온 줄 알게 되고, 정작 이번에 바뀐 게 뭔지 묻히니까요.

**뺀 것** — 큰 사진 자동 줄이기, 프로젝트 메모 백업 수정, 도안 PDF 클라우드 보관.
셋 다 클라우드 백업을 쓸 수 있어야 눈에 띄는 것이라, 지금 테스터분들께는
무슨 말인지 알 수 없는 항목입니다.

## ⚠️ 업데이트가 막힌 분께 — 위 공지 뒤에 덧붙이기

**백업 안내를 빼면 안 됩니다.** 앱 기록은 폰 안에만 있어서 그냥 지우면 사라집니다.

```
혹시 "업데이트할 수 없음"이 뜨시나요? 🙏

앱을 지우고 다시 받으셔야 해요. 번거롭게 해서 죄송합니다.

⚠️ 지우기 전에 꼭 백업해 주세요!
앱의 기록은 폰 안에만 있어서, 그냥 지우면 사라집니다.

1) 앱 → 설정 → 백업 → "파일로 내보내기"
   파일 하나가 저장돼요. 사진까지 다 들어있습니다.

2) 앱 삭제

3) 아래 링크로 다시 설치
   https://play.google.com/apps/testing/com.suki.knittinglog

4) 앱 → 설정 → 백업 → "파일에서 가져오기"
   1번에서 받은 파일을 고르면 그대로 돌아옵니다.

백업 파일을 잃으실까 걱정되면 저한테 보내두셔도 괜찮아요.
```
