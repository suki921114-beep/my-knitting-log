## 위젯 다는 법 (문의가 오면)

```
홈 화면 빈 곳을 꾹 누르기
→ 위젯
→ 뜨개일기
→ '단수 세기' 또는 '도안 보기' 고르기
→ 어떤 프로젝트를 볼지 고르기

도안 보기 위젯은 앱에서 그 도안을 한 번 열어보셔야 떠요.
보던 쪽을 기억해서 띄우는 방식이라 기록이 있어야 합니다.
```

## 이번 빌드에 들어간 것 (1.12.0 ~ 1.14.1)

- 홈 화면 위젯 두 종류 (단수 세기 / 도안 보기)
- 위젯마다 프로젝트 고르기, 크기 조절, 눌러서 '도안 보며 뜨기'로
- 실 사용량을 프로젝트·실 상세에서 바로 수정
- 실·부자재·바늘·도안에서 '사진 찍기' 선택
- 다이어리 기분 이모지 10개 + 직접 넣기

### 겉으로 안 보이지만 고친 것

- 도안 PDF 업로드가 사진 상한(2MB)에 막히던 문제
- 계정을 지워도 도안 PDF가 클라우드에 남던 문제
- 앱 전체 삭제 뒤 도안 파일이 기기에 남아 용량을 차지하던 문제
- 이용약관 3항이 뜻과 반대로 적혀 있던 것
- 개인정보처리방침에 도안 PDF 항목 추가
- 오픈소스 고지에 PDF.js 등 7개 누락분 추가

## 미룬 것

**R8 최적화** — Play Console 권장 조치에 뜨지만 지금은 켜지 않습니다.
Capacitor 플러그인은 이름으로 찾아 쓰는 구조라 R8 이 안 쓰는 줄 알고
지울 수 있고, 그러면 release 빌드에서만 위젯·로그인이 조용히 죽습니다.
켤 때는 이것만 따로 한 버전으로 올리고, release 빌드를 직접 깔아
위젯·로그인·PDF 를 눌러 보고 넘길 것.

**넓은 화면(edge-to-edge)** — 권장 조치에 뜨지만 조치 완료 상태입니다.
인셋을 CSS(`env(safe-area-inset-*)`)에서 이미 처리하고 있습니다.
안내문의 `enableEdgeToEdge()` 는 네이티브로 화면을 그리는 앱용입니다.
