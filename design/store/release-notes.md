# 뜨개일기 출시 준비물 — 현재 버전

versionName `1.8.1` / versionCode `34`

> 이 파일 하나만 씁니다. 버전이 올라가면 여기 내용을 덮어쓰세요.
> `release-notes-1.7.*.md`, `release-notes-1.8.0.md` 는 지우셔도 됩니다.

## 담은 범위

테스터분들이 아직 도안 기능을 못 받으셨습니다. **1.7.0 부터 1.8.1 까지 한 번에** 담았습니다.

**뺀 것** — 큰 사진 자동 줄이기, 프로젝트 메모 백업 수정, 도안 PDF 클라우드 보관.
셋 다 클라우드 백업을 쓸 수 있어야 눈에 띄는 것이라, 지금 테스터분들께는
무슨 말인지 알 수 없는 항목입니다.

## Play Console 출시 노트

```
도안 PDF와 게이지 검색이 들어왔어요.

· 도안에 PDF 파일을 넣고 앱 안에서 바로 보기
· 도안 보며 뜨기 — 위에는 단수 카운터, 아래는 도안
· 손가락으로 벌려서 원하는 자리를 확대할 수 있어요
· 뜨는 동안 화면이 꺼지지 않아요
· 도안에도 게이지를 적을 수 있어요
· 게이지로 실과 도안을 찾을 수 있어요 (4.0mm, 22코)
· 라이브러리에서 실·도안·바늘·부자재를 한 번에 검색해요
· 실을 일반실/염색실로 나눠 볼 수 있어요
· 프로젝트에 바늘을 걸 때 호수만 적으면 바로 등록돼요
· 저장한 뒤 뒤로가기가 한 번에 안 먹던 문제를 고쳤어요
· 지운 항목의 화면이 뒤로가기에서 다시 나오던 문제를 고쳤어요
```

## 인스타그램 공지

```
업데이트 올라갔어요! (v1.8.1)

도안 기능이 통째로 들어왔어요. 오래 미뤄뒀던 건데 드디어 넣었습니다.


📄 도안 PDF

· 도안에 PDF 파일을 넣어두면 앱에서 바로 볼 수 있어요
· 손가락으로 벌리면 그 자리가 확대됩니다. 두 번 톡 해도 돼요
· 보던 장을 기억해요. 앱을 닫았다 열어도 그 자리부터예요
· 인터넷 없이도 열립니다


🧶 도안 보며 뜨기

프로젝트에 도안을 걸어두면 홈 화면에 '도안 보며 뜨기'가 생겨요.
누르면 화면이 위아래로 갈라집니다.

· 위에는 단수 카운터, 아래에는 도안
· 한 단 뜰 때마다 뒤로 나갔다 올 필요가 없어요
· 가운데 손잡이를 끌어서 위아래 크기를 바꿀 수 있어요
· 뜨는 동안 화면이 꺼지지 않습니다
· 카운터를 그 자리에서 만들고 고칠 수 있어요


🔍 게이지로 찾기

"이 실에 맞는 도안이 뭐가 있더라?" 를 앱이 대신 찾아줍니다.

· 도안에도 게이지를 적을 수 있어요
· 실 목록과 도안 목록에서 게이지로 검색돼요
  4.0mm, 22코 처럼 아무렇게나 쳐보세요
· 라이브러리 첫 화면에서 실·도안·바늘·부자재를 한 번에 찾아요
  그게 실인지 바늘인지 기억 안 날 때 쓰시면 돼요


✏️ 실

· 일반실 / 염색실로 나눠 볼 수 있어요
· 게이지를 메리야스/무늬, 세탁 전/후로 나눠 적을 수 있어요
· '무메'라는 말을 '메리야스'로 바꿨어요
· 바늘 호수는 숫자만 적으면 mm가 알아서 붙습니다


🔧 알려주신 것 고쳤어요

· 저장하고 뒤로가기를 눌러도 화면이 그대로이던 문제
  이제 한 번만 눌러도 돌아갑니다
· 지운 실을 뒤로가기로 만나면 "삭제된 실"이 뜨던 문제
  이제 바로 목록으로 갑니다
· 프로젝트에 바늘을 걸 때 호수만 적으면 바로 등록돼요
  (3.5, 4, 4.5 처럼 여러 개도 한 번에)
· 게이지 적는 칸이 뭉개지던 문제
· 도안 파일이 간혹 "손상되었을 수 있어요"라며 안 열리던 문제


⚠️ 하나만 부탁드려요

도안 파일은 이 기기에만 저장됩니다.
앱을 지우거나 폰을 바꾸면 같이 사라져요.
원본은 꼭 따로 보관해 주세요.


업데이트 방법
Play 스토어 → 오른쪽 위 프로필 → 앱 및 기기 관리 → 업데이트 사용 가능
설정 → 앱 정보에서 1.8.1이면 최신이에요. 반영까지 몇 시간 걸릴 수 있습니다.


불편한 거 알려주셔서 고맙습니다 🙏
설정 → 의견 보내기로 계속 말씀해 주세요.
```

## ⚠️ 업데이트가 막힌 분께 — 위 공지 뒤에 덧붙이기

**백업 안내를 빼면 안 됩니다.** 앱 기록은 폰 안에만 있어서 그냥 지우면 사라집니다.

```
혹시 "업데이트할 수 없음"이 뜨시나요? 🙏

앱을 지우고 다시 받으셔야 해요. 번거롭게 해서 죄송합니다.

⚠️ 지우기 전에 꼭 백업해 주세요!
앱의 기록은 폰 안에만 있어서, 그냥 지우면 사라집니다.

1) 앱 → 설정 → 백업 → "파일로 내보내기"
   파일 하나가 저장돼요. 사진까지 다 들어있습니다.

2) 앱 삭제

3) 아래 링크로 다시 설치
   https://play.google.com/apps/testing/com.suki.knittinglog

4) 앱 → 설정 → 백업 → "파일에서 가져오기"
   1번에서 받은 파일을 고르면 그대로 돌아옵니다.

백업 파일을 잃으실까 걱정되면 저한테 보내두셔도 괜찮아요.
```
