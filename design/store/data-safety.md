# Play 콘솔 · 앱 콘텐츠 (데이터 안전성) 작성표

기준: 뜨개일기 1.7.0 / versionCode 29
확인 방법: 코드에서 **기기 밖으로 나가는 것**만 추렸습니다.

> Google 기준으로 '수집'은 **기기 밖으로 전송되는 것**만 말합니다.
> 기기 안에만 있는 것은 신고 대상이 아닙니다.

---

## 0. 먼저 알아둘 것

**안드로이드 권한은 손댈 게 없습니다.** 매니페스트에 `INTERNET` 하나뿐이고,
사진은 시스템 파일 선택기·카메라 앱을 빌려 쓰므로 카메라·저장소 권한이 필요 없습니다.

**도안 PDF는 신고 대상이 아닙니다.** 기기에만 저장되고 어디로도 보내지 않습니다.

---

## 1. 기기 밖으로 나가는 것

| 무엇 | 언제 | 어디로 |
|---|---|---|
| 이름 · 이메일 · 프로필 사진 | 구글 로그인할 때 | Firebase Authentication |
| 사용자 ID (uid) | 로그인 상태에서 | Firestore / Storage |
| 사진 | 클라우드 백업을 누를 때 | Firebase Storage |
| 기록 글 (프로젝트 · 실 · 다이어리 등) | 클라우드 백업을 누를 때 | Firestore |
| 앱 버전 · 브라우저 정보 | 의견 보내기를 누를 때 | Cloud Functions → 메일 |
| 사용자가 쓴 의견 내용 | 의견 보내기를 누를 때 | Cloud Functions → 메일 |

⚠️ 클라우드 백업은 지금 허용된 계정만 쓸 수 있지만, **앱이 보낼 수 있는 구조**라면
신고해야 합니다. 덜 신고했다가 걸리는 쪽이 훨씬 손해입니다.

---

## 2. 설문 답안

### 데이터 수집 여부
> **예, 이 앱은 사용자 데이터를 수집하거나 공유합니다**

### 전송 중 암호화
> **예** — 전부 HTTPS(Firebase)로 나갑니다

### 데이터 삭제 요청
> **예, 사용자가 데이터 삭제를 요청할 수 있습니다**
> URL: 설정 → 계정 삭제 화면 안내 (개인정보처리방침 URL 과 같은 곳에 적어 두기)

### 제3자 공유
> **아니요** — Firebase 는 처리를 맡기는 곳이지 공유 대상이 아닙니다

---

## 3. 항목별 체크

각 항목마다 **수집 / 공유 / 필수인지 / 목적**을 묻습니다.
공유는 전부 **아니요**, 필수는 전부 **선택(사용자가 선택할 수 있음)** 입니다.

### 개인 정보

| 항목 | 수집 | 목적 |
|---|---|---|
| 이름 | 예 | 앱 기능 |
| 이메일 주소 | 예 | 앱 기능, 고객 지원 |
| 사용자 ID | 예 | 앱 기능 |

- 이름·이메일: 구글 로그인과 의견 보내기 답장에 씁니다
- 사용자 ID: 누구의 백업인지 가르는 데 씁니다

### 사진 및 동영상

| 항목 | 수집 | 목적 |
|---|---|---|
| 사진 | 예 | 앱 기능 |

- 클라우드 백업을 누를 때만 올라갑니다
- **'선택'** 으로 표시 — 로그인·백업을 안 하면 기기 밖으로 안 나갑니다

### 앱 활동

| 항목 | 수집 | 목적 |
|---|---|---|
| 기타 사용자 제작 콘텐츠 | 예 | 앱 기능 |

- 프로젝트·실·다이어리에 적은 글, 그리고 의견 보내기 내용

### 앱 정보 및 성능

| 항목 | 수집 | 목적 |
|---|---|---|
| 진단 | 예 | 고객 지원 |

- 의견 보내기에 앱 버전과 브라우저 정보가 함께 갑니다

### 신고하지 않는 것

- 위치, 금융 정보, 건강, 연락처, 메시지, 통화 기록, 검색 기록 — 전부 안 씁니다
- **파일 및 문서** — 도안 PDF 는 기기에만 있고 보내지 않습니다
- **기기 또는 기타 ID** — 광고 ID 를 쓰지 않습니다
